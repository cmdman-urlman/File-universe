Your drives are universes. Fly into them.

File Universe Explorer turns your real disks into a navigable 3D cosmos. Folders become galaxies, star clusters, planets and moons. Files are the stars around them. Every name, size and path on screen comes straight from your disk.

How the filesystem maps to the cosmos

Every folder level is a different scale of space

The deeper a folder sits below the drive root, the smaller the object it becomes. Here is one real-looking path, followed all the way down.

  1. 0

    Universe

    Shaped like the hardware: SSD slab, HDD platters, USB stick, SD card, disc

    C:\

  2. 1

    Spiral galaxy

    Files are stars along the spiral arms

    C:\Users

  3. 2

    Galaxy region (nebula)

    Stars spread through the nebula volume

    C:\Users\you

  4. 3

    Globular star cluster

    Stars packed into a dense ball

    …\you\Pictures

  5. 4

    Planetary system

    Files are exoplanets on Keplerian orbits. Photos are wrapped onto them as textures

    …\Pictures\2024

  6. 5

    Planet

    Terrestrial or gas giant. Files grow as crystals on the surface

    …\2024\Lapland

  7. 6

    Moon

    Crystals on the surface. Craters follow its curve

    …\Lapland\Day 3

  8. 7

    Crater

    Files are pebbles on the crater floor

    …\Day 3\RAW

  9. 8

    Rock

    Pebbles in shells around the rock

    …\RAW\rejects

  10. 9

    Sand grain

    Quartz, surrounded by particles

    …\rejects\old

  11. 10+

    Microbe → molecule → atom → quantum particle

    Then the cycle repeats at a smaller scale, forever

    …\old\backup\…

There is no depth limit. The scene is always re-rooted at the folder you are in, so depth 50 is as precise and as fast as depth 1. Entering a folder zooms the camera into it, and the same object becomes the new centre at the same size on screen.

Size → visual size

A terabyte is only twelve times bigger than a kilobyte

Byte counts span twelve orders of magnitude, so sizes are compressed on a log scale. Big folders still look big, and small ones stay visible. The properties panel always shows the exact byte count next to the radius.

radius = 0.12 · 1.32log₁₀(bytes)

What you get

A real file explorer under the starfield

Opens files like Explorer

Double-click a folder to fly into it. Double-click a file to open it in its default app.

Safely remove drives

Right-click a USB stick or SD card to eject it. If a program still has files open, the app says so. Multi-slot card readers are handled as one device.

Hot-plug

New drives fade in within two seconds. Unplug the drive you are in and its universe dissolves, then you return to This PC.

Previews

Image thumbnails, video frames and audio waveforms in the properties panel. Install ffmpeg to get frames and waveforms for MP3, FLAC, OGG and M4A.

Search

Name search with * and ? wildcards below the current folder, or across every drive. Double-click a result to fly to it.

Built for big disks

Instanced rendering keeps 20,000 objects at about 40 fps on a GTX 1650. Folder sizes are measured once in the background and cached.

Install

Running in a minute

  1. Get Python 3.12 or newer

    From python.org, with the py launcher. No administrator rights needed.

  2. Download the source

    Clone the repository or download it as a ZIP.

  3. Install and launch

    Run the two commands in the project folder. The app starts at This PC, with every drive as its own universe.

Command Prompt
rem install dependencies
py -m pip install -r requirements.txt
rem launch
py main.py
rem or start inside a folder
py main.py --path "C:\Users"
